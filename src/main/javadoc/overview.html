JWhisper Client GUI Overview

The jw-client-gui artifact is the modern, desktop-facing rich user interface for JWhisper end-users. It abstracts complex cryptographic actions into a clean, responsive layout utilizing JavaFX, the AtlantaFX theme engine, and a dynamic view navigation routing system while maintaining rigorous client-side End-to-End Encryption (E2EE).

Key Structural Pillars

  • io.github.artshp.jwhisper.client.gui.controller: Binds user actions to application behavior. Manages user states across specialized workspaces including initial node handshakes (LocalSetup), secure profile authentication (Login), and real-time chat timelines (Home).
  • io.github.artshp.jwhisper.client.gui.navigation: Implements a functional, decoupled SceneSwitcher registry engine. Replaces rigid conditional factories with a dynamic map configuration of manual constructor injection rules, ensuring smooth runtime route updates across layouts.
  • io.github.artshp.jwhisper.client.gui.state: Acts as the localized application memory brain. Leverages non-blocking concurrent data structures like CopyOnWriteArrayList to safely manage and dispatch incoming message events across the background WebSocket thread and the active JavaFX Application context thread.

UI Experience Enhancements

  • AtlantaFX Dark Theme Integration: Configured natively using looked-up CSS variables and structural typography rules to eliminate unneeded styles and ensure elegant contrast ratios.
